# Random Projects 

Coleção de scripts e ferramentas utilitárias desenvolvidos para auxiliar atividades administrativas, operações de infraestrutura, automação de tarefas e troubleshooting em ambientes Linux e corporativos.

## Objetivo

Este repositório centraliza pequenos scripts criados para resolver necessidades específicas do dia a dia, facilitando a reutilização de soluções já implementadas e reduzindo o tempo gasto com tarefas repetitivas.

Os scripts podem abordar diferentes áreas, incluindo:

- Administração de sistemas Linux
- Automação de rotinas
- Gestão de infraestrutura
- Operações de rede
- Segurança da informação
- Manipulação de arquivos e logs
- Geração de hashes e credenciais
- Ferramentas de suporte técnico
- Scripts de diagnóstico e troubleshooting

## Estrutura

Cada script possui um propósito específico e, sempre que possível, inclui comentários internos descrevendo:

- Objetivo da ferramenta
- Requisitos de execução
- Forma de utilização
- Exemplos de uso

## Scripts atuais

### analisa_ips_rede.py
Identifica IPs ausentes em uma sequência de endereços, testa sua disponibilidade na rede e gera uma lista dos IPs livres para utilização.

### digita_texto.py
Automatiza a digitação de textos armazenados em arquivos, enviando o conteúdo para uma janela selecionada pelo usuário através do mouse.

### gera_sha.sh
Gera hashes de senha no formato {SHA} (SHA-1 em Base64) a partir de uma senha informada e validada pelo usuário.

### merge_pdfs.py
Une múltiplos arquivos PDF em um único documento, mantendo a ordem dos arquivos informados na execução.
